# pilotproject-automatic-protocols

Project-level instructions for Claude Code. The user-level `~/.claude/CLAUDE.md` still applies in every session; this file adds repo-specific configuration and is committed with the repo.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `aihpi/pilotproject-automatic-protocols`, using the `gh` CLI. External pull requests are **not** a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each mapped to a label string equal to its name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.
